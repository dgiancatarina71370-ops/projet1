# Protocole de test M6 (traçabilité calculée), sur votre clé USB

Prérequis : GitHub Actions vert sur les trois jobs (`verify` avec **297 tests**, `rust-tests`, `build`). Le lot **n'ajoute aucune donnée** : schéma 6 inchangé, pas de migration, pas de sauvegarde pre-migration. Il ajoute un écran en lecture seule, un menu « Contrôle » et **un mécanisme d'ouverture de fiche** branché sur les sept écrans de registre : les tests 12 à 14 le vérifient partout. Notez OK / ÉCHEC et une capture en cas d'échec.

**Précaution** : copiez votre dossier de travail (exécutable et `BAMentorData`, au schéma 6) dans **deux** dossiers neufs : `Test-avant` (exécutable **0.7.0**) et `Test-M6` (exécutable **0.8.0**).
