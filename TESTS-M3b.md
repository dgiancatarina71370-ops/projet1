Les 158 tests existants avant M3b (dont tous ceux de M3a) sont rejoués dans la même suite ; 37 tests s'y ajoutent (195 au total). **Non couvert automatiquement** : les clics, les saisies, le changement de statut en un clic, l'ajout et le retrait de liens dans la fiche, l'enchaînement des écrans. C'est l'objet des tests 7 à 24.
