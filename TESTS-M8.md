# Protocole de test M8 (livrables générés), sur votre clé USB

Prérequis : GitHub Actions vert sur les trois jobs (`verify` avec **365 tests**, `rust-tests`, `build`). Le lot **ne change pas le schéma** (toujours la version 7) et ne modifie aucune donnée : il ajoute l'écran **Livrables**, un bouton sur la fiche d'un atelier et sept modèles de documents générés à partir de vos données. Notez OK / ÉCHEC et une capture en cas d'échec.

**Précaution** : copiez votre dossier de travail (exécutable et `BAMentorData`, au schéma 7) dans **deux** dossiers neufs : `Test-avant` (exécutable **0.9.0**) et `Test-M8` (exécutable **0.10.0**). Utilisez un projet qui contient de vraies données (au moins un atelier relié à des éléments, des exigences de priorités différentes, une user story, un test, une décision qui en remplace une autre, un risque) ; sinon créez-les dans le projet de test.

Couvert par les tests automatiques (pas par cette grille) : contenu exact de chacun des sept modèles (tri, périmètre, synthèse, sens des liens, remplacements des décisions, statuts inconnus), neutralisation du texte saisi dans tous les champs de tous les types (structure Markdown analysée : aucun titre, bloc de code, règle ni lien déguisé produit par du texte saisi), libellés de la matrice identiques à ceux de l'écran Traçabilité, lecteur limité au projet et aux détails du bon type, export de bout en bout des 7 modèles dans les 3 formats avec signature relue dans le fichier Word, absence de toute écriture (tables identiques avant et après), transmission de l'option d'archivage et de l'atelier choisi, erreurs (modèle, projet, atelier, version inconnue), logique et rendu statique de l'écran, branchement de l'application, 200 exigences en Word. Une soixantaine de casses volontaires du code ont été faites ; trois avaient survécu et ont conduit à deux tests de plus, toutes sont ensuite détectées.

**Non vérifié ici** : ouverture dans Microsoft Word (message de réparation, largeur des colonnes, surtout la matrice), compilation Windows, boîte « Enregistrer sous… », clics, aperçu et fluidité sur un très gros projet.
